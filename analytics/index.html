⚡ Upstash Redis Configuration Required

Your analytics endpoints are deployed! To start storing live traffic, connect a free Upstash Redis database in Vercel:

  1. Log in to Upstash.com and click Create Database (Free tier: 10,000 commands/day).
  2. Scroll down to the REST API section on your database page.
  3. Go to your Vercel Project Dashboard > Settings > Environment Variables and add:
    • UPSTASH_REDIS_REST_URL = Your Upstash REST URL
    • UPSTASH_REDIS_REST_TOKEN = Your Upstash REST Token
    • ADMIN_PASSWORD = Your chosen secret password for this dashboard
  4. Trigger a redeploy on Vercel or commit a change. That's it!
